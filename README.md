## 数学公式与符号约定

行内公式两侧各用一个美元符号，独立公式默认用单独成行的两个美元符号。多行推导可用 `aligned`，部分长公式保留 `math` 围栏以兼容 GitHub 渲染。

| 符号 | 含义 |
| --- | --- |
| $h_\theta$ | 假设函数 |
| $L$、$\ell = \log L$ | 似然、对数似然 |
| $J$ | 代价函数；第 2.3 节为负对数似然 |
| $\ell_{\mathrm{ce}}$ | 单样本交叉熵损失 |
| $w^{(i)}$ | 局部加权回归的样本权重 |
| $w$、 $b$ | SVM 权重向量、偏置 |
